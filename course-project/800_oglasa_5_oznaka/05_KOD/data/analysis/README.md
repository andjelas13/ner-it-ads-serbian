# Ulazi za analizu izveštaja

`calibration_50/` sadrži četiri nezavisne ljudske anotacije i odvojenu GPT anotaciju nad istih 50 oglasa. One služe skriptama `human_agreement.py` i `gpt_vs_human.py`.

`revision_inputs/init_annotations_1000.json` je sačuvani spoj istorijskih INIT anotacija (ukupno 1.000 oglasa i 14.416 anotacija), korišćen za objavljenu INIT -> FINAL analizu. Pojedinačni istorijski batch ulazi nisu deo finalnog reprodukcionog repozitorijuma.
